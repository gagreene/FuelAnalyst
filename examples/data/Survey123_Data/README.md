# Demonstration Dataset

FuelAnalyst and ConPyro demonstration dataset compiled by Rachel Pekelney in August 2026. Contact: rachel.pekelney@ubc.ca or rpekelney@berkeley.edu.

This dataset contains a subset (n = 20) of field measurements taken in British Columbia. Field measurements were taken in treated and untreated units, pre- and post-wildfire. Pre-fire measurements were taken in summer 2021; post-fire measurements were taken in fall 2021.

The data have been anonymized for privacy reasons.
